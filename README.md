# TOPMYY

Примеры статических страниц для переноса на сервер.

## 404 страница
Откройте файл [`404.html`](404.html), чтобы посмотреть макет ошибки *Страница не найдена*.

## Пример приложения
Файлы демонстрируют последовательность экранов:

- [`login.html`](login.html) — форма входа
- [`greeting.html`](greeting.html) — приветствие пользователя
 - [`home.html`](home.html) — главная с приветствием, текстовым описанием, блоком новостей и меню
- [`permissions-form.html`](permissions-form.html) — форма цифрового разрешения
- [`permissions-pending.html`](permissions-pending.html) — заявка отправлена
- [`permissions-approved.html`](permissions-approved.html) — заявка одобрена
- [`permissions-link.html`](permissions-link.html) — итоговый экран с ссылкой

Каждый файл автономен и готов к размещению на сервере.
